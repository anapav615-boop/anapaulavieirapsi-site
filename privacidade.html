Política de Privacidade

Última atualização: Novembro/2025

Esta Política de Privacidade explica como são coletados, utilizados e protegidos os dados pessoais das pessoas que acessam o site anapaulaapvieirapsi.com.br, de titularidade de Ana Paula Ap. Vieira – Psicóloga Clínica (CRP 06/217114).

1. Dados coletados

Os dados podem ser coletados de três formas:

1.1. Dados fornecidos por você

  • Nome;
  • E-mail;
  • Telefone (quando informado);
  • Mensagem enviada pelo formulário de contato.

1.2. Dados coletados automaticamente

  • Endereço IP;
  • Navegador e sistema operacional;
  • Páginas visitadas e tempo de navegação;
  • Informações técnicas necessárias para o funcionamento do site.

1.3. Cookies

Este site utiliza cookies essenciais e algumas tecnologias semelhantes para lembrar preferências básicas, melhorar a navegação e cumprir exigências legais. Você pode configurar o seu navegador para bloquear cookies, mas isso pode limitar algumas funcionalidades.

2. Finalidade do uso dos dados

Os dados coletados são utilizados para:

  • Responder mensagens enviadas pelo formulário de contato;
  • Auxiliar no agendamento de atendimentos psicológicos;
  • Melhorar o conteúdo e a navegação do site;
  • Cumprir obrigações legais e regulatórias;
  • Garantir segurança e prevenção de usos indevidos.

Seus dados não são vendidos nem utilizados para publicidade invasiva.

3. Compartilhamento de dados

Os dados pessoais poderão ser compartilhados apenas quando necessário:

  • Para cumprimento de obrigações legais ou decisões judiciais;
  • Com serviços de hospedagem e infraestrutura do site (como Netlify e provedores de e-mail);
  • Com ferramentas de análise de tráfego, como Google Analytics, quando utilizadas.

O tratamento de dados respeita as normas éticas da Psicologia e a legislação brasileira de proteção de dados pessoais.

4. Armazenamento e segurança

Os dados são armazenados em ambiente com medidas razoáveis de segurança para impedir acessos não autorizados, alterações ou perda indevida. Informações de prontuário psicológico não são registradas neste site.

5. Direitos da pessoa usuária

Você pode, a qualquer momento, solicitar:

  • Acesso aos dados pessoais que foram informados;
  • Correção ou atualização de informações;
  • Exclusão de dados que não sejam mais necessários;
  • Esclarecimentos sobre o tratamento dos seus dados.

Os pedidos podem ser enviados para o e-mail contato@anapaulaapvieirapsi.com.br.

6. Links externos

Este site contém links para outros serviços, como WhatsApp, Google Maps, Instagram, Facebook e LinkedIn. Cada serviço possui sua própria política de privacidade, pela qual não temos responsabilidade.

7. Atualizações desta política

Esta Política de Privacidade pode ser atualizada conforme ajustes técnicos ou legais do site. A versão vigente estará sempre disponível nesta página, com a data de atualização indicada no início do texto.
